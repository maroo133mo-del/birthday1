شاهي - صفحة عيد الميلاد

index.html : الصفحة (افتحه بأي متصفح، أو ارفع الفولدر كله على أي استضافة)
images/    : الصور (بدّل أي صورة بنفس الاسم أو غيّر الاسم جوه index.html)
song.mp3   : الأغنية

للتعديل افتح index.html بأي محرر نصوص وابحث عن:
- الجمل اللي تحت الصور: جوه <p> بعد كل صورة
- الرسالة الأخيرة: جوه <div class="paper">
- تاريخ العد التنازلي: new Date(2026,10,2,...) (الشهر ١٠ = نوفمبر)
